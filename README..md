# MUL20 – Multimédia: Plachetnice na moři

**Typ projektu:** 3D animace / audiovizuální dílo
**Autor:** [DOPLNIT JMÉNO A PŘÍJMENÍ]
**Použitý software:** Blender 4.2.3 LTS

## 1. Popis projektu

Projekt představuje vlastní 3D animaci plachetnice
na mořské hladině, která se pohybují plachty a houpe se na mořských vlnách a vše doprovází zvuk racků a mořských vln.

## 2. Použité technologie

- **Blender:** Modelování a animace
- **Cloth:** Fyzikální simulace plachet
- **Ocean:** Simulace mořské hladiny
- **Kamery:** Více pohledů na plachetnici
- **Video Sequencer:** Titulky a zvuková stopa
- **Světlo:** Osvětluje celou scénu

## 3. Technické parametry

- **Rozlišení:** 1920 × 1080 (Full HD)
- **Snímková frekvence:** 30 FPS
- **Délka:** 60 sekund
- **Formát:** MP4
- **Kodek:** H.264
- **Zvuk:** AAC
